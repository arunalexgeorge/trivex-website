# Trivex Industrial Solutions — Website

Production-ready **multi-page** marketing website for **Trivex Industrial Solutions FZC**
(SAIF Zone, Sharjah, UAE) — complete industrial solutions for water & wastewater, oil & gas,
mining and heavy process industries.

Dependency-free static site generated by `tools/build_html.py`. Design language derived from the
client's `doc.pdf` mockup; brand logo vectorized from `client_data/logo_green.jpeg`. Clean
directory-index URLs (`/products/<slug>/`) that work on any static host with browser refresh and
direct navigation.

## Pages / routes

```
/                                 Home (hero slideshow, featured products/services, industries, why-us, projects, CTA)
/about/                           About
/products/                        Products overview (category filter + deep-link #category)
/products/<slug>/                 36 product detail pages (hero, tabs, specs, applications, FAQ, related, enquiry)
/services/                        Services overview
/services/<slug>/                 8 service detail pages (hero, problem, process timeline, capabilities, FAQ)
/industries/                      Industries & solutions (6 sectors)
/projects/                        Project gallery (filterable + lightbox)
/contact/                         Contact (details, map, quote form)
robots.txt  sitemap.xml           (sitemap auto-generated with all 51 URLs)
```

## Structure

```
tools/build_html.py     ← multi-page generator. Data tables: PRODUCTS, SERVICES, INDUSTRIES, PROJECTS.
tools/data/             ← inline SVG logo data used by the generator.
assets/css/styles.css   ← design system + all components (nav/mega-menu, product detail, tabs, accordion,
                          timeline, cards, WhatsApp float, view transitions, responsive).
assets/js/main.js       ← nav dropdowns, mobile drawer + submenus, tabs, FAQ accordion, count-up stats,
                          product/project filters (+#hash deep-link), lightbox, hero slideshow, contact form.
assets/img/             ← brand (SVG logo, favicons), 36 products, 8 solutions, clients, backgrounds, projects.
```

## Develop / build

```bash
python3 tools/build_html.py      # regenerate all pages + sitemap after editing content in the generator
python3 -m http.server 8099      # preview at http://localhost:8099
```

Content (product/service/industry copy, benefits, FAQs) lives in the data tables at the top of
`tools/build_html.py`. Editing only CSS/JS needs no rebuild.

## Configuration

- **WhatsApp:** `WHATSAPP_NUMBER` constant in `tools/build_html.py` (international format, no `+`).
  A floating WhatsApp button appears on every page; product/service pages pass a **contextual**
  pre-filled message (e.g. *"Hello, I am interested in <Product>…"*).
- **Contact:** `PHONE_TEL`, `EMAIL`, `SITE` constants. The quote form has no backend — it composes a
  `mailto:` and pre-fills from `?product=` / `?service=` / `?industry=` query params. Wire it to a
  form endpoint (Formspree, Netlify Forms, etc.) for server-side handling.

## Deploy

Upload the whole project root (minus `.pdf_render/`, `tools/`, `doc.pdf`, `extracted_images/`,
`client_data/` which are build/source-only) to any static host (Netlify, Vercel, S3/CloudFront,
Nginx, GitHub Pages). Update absolute URLs (canonical/OG, `SITE`, `sitemap.xml`) if the domain changes.
